# Version 0.1.0 — Alibaba pilot

Initial Accio Work package for AI Shopping Auditor.

Included:

- Accio-native `plugin.json`
- Public AI Shopping Auditor SubAgent
- Global Amazon AI Shopping Visibility Audit Skill
- Buyer-question taxonomy
- Evidence, claim, scoring, output, and QA references
- Synthetic example
- English and Simplified Chinese primary metadata
- Static package validator
- Reproducible ZIP builder and SHA-256 checksum

Static validation and archive integrity have passed for this release. Runtime import and end-to-end behavior inside the target Accio Work build remain a separate acceptance step.
